## 快速使用

**作为 Hermes/Claude skill**：安装后，当用户提供六爻卦象时，加载 `SKILL.md`（聚合总纲）按七步断卦法执行；细节模块按需读 `references/` 对应文件。

**核心方法**：

- 两层面分离：吉凶层循卦理（严谨）、应期细节层取象（飘逸）——不可混用
- 七步断卦：读盘 → 定卦种 → 取用神 → 评旺衰 → 定吉凶 → 对轨 → 应期细节
- 静卦三步：用忌持世 → 世用生克 → 用旺世兴
- 动卦五局：世用受生/用神生世/用旺世兴=吉；用衰/世伤/世用受克/用旺世衰/用神克世=凶（求财/行人/医药/忧患四例外）
- 应期 20 公式 + 5 原则（吉应凶应/盯面不盯点/应众不应寡/应早不应迟/应邻不应单）
- 特殊信号：占此应彼五大规律、错卦正显、灾卦四公式、心态卦（子孙喜/官鬼忧）
