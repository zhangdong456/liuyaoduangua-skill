## 二、整书主旨（结构）

朱辰彬的古筮六爻体系，核心主张：

1. **两层面分析**：吉凶判断层面（卦理为主，重逻辑）与应期细节层面（飘逸思维，重取象）严格分层；两层面理论不可混用（如"月绊"吉凶层面不存在、化进退短事无效等）。
2. **动必有因**：动爻是吉凶定性的核心，需辨析有用/无用动爻、真假动兆、复合连动、三合局。
3. **世用关系定吉凶**：用神必须旺相；自占自事世爻不能受动克或自变衰败；四大吉局（世用受生/用神生世/用旺世兴）+ 五大凶局（用神衰败/世爻受伤/世用受克/用旺世衰/用神克世）。
4. **卦种先行**：先辨事卦 / 心态卦 / 现状卦 / 应期卦 / 指导卦 / 特殊时效卦 / 双核卦 / 连占卦，再按卦种规则解卦。
5. **意念决定论**："只答心念不答口述"、错卦正显、预兆舍远应近、显像就重避轻、意念扶正伐邪、所答不谋专事。
6. **现状对证**：日月、动变、旬空、暗动等均可与客观现状对证，验证用神真伪（真用神五特征：世应/两动/日月/空墓）。
7. **应期公式化**：20 条应期公式 + 5 条应期原则（吉断吉应/盯面不盯点/应众不应寡/应早不应迟/应邻不应单）。
8. **化解凶卦**：9 条主动化解方法（放弃、冲起元神、制约忌神等），强调"卦象趋势可因人而变"。

## 三、关键概念骨架

- **日月动变四因素**：月令、日令、动爻、变爻 → 爻之旺衰的四个来源
- **无用动爻四型**：回头克、化退、化破散、化绝（共同特征：动而变衰）
- **暗动六条件**：月旺受冲/月气受冲/冲空/动爻趋旺/用趋世兴/动不为散
- **静卦三步骤**：用忌持世 → 世用生克 → 用旺世兴
- **卦意分析法**：世化用忌、用忌互化、鬼用互化、世动化鬼、世用背向、搭桥趋变、牵连聚合、代入确认、藏爻确认、间爻阻隔、冲合预兆、动动相连
- **三合局**：吉凶层面三爻皆动；应期找破绽（空/破/墓/绊/缺一）
- **应期加速/迟缓器**：暗动、带日令而动、卦变六冲=加速；三合、三绊、卦变六合=迟缓
- **特殊日月组合**：旺相式（月建日建/月合日建/日合月建/日合月合等）、衰败式（月破日克/月破日墓/月破日绝）
- **心态卦喜忧神**：子孙=喜神（放心）、官鬼=忧神（忧虑）

## 四、解释（为什么这套体系有效）

1. **层次分明**：吉凶看卦理、细节看取象，避免了一锅粥式的混断。
2. **可验证性**：强调"现状对证"——用已知客观事实校验卦象，识别真假用神、真假应期卦。
3. **概率思维**：承认固定套路只有"概率上的准确性"，不追求绝对神断。
4. **意念第一性**：把"心念"作为卦象解读的最高依据，发展出心念爻、读心术等独特技法。

## 五、批判（作者的盲点/边界）

1. 部分理论（如心念爻定位、指导卦、灾卦时效）缺乏大规模统计验证，主观性较强。
2. 案例多为事后验证、挑选性呈现，存在幸存者偏差风险。
3. 股市应用部分，作者自己强调古筮只能作为"分析参考"而非决策工具（"不谋专事"）。
4. 应期细节层面的"飘逸思维"开放度过高，初学者易陷入过度联想。
5. 扫描版《占此应彼》《弟子班内部资料》未纳入本次蒸馏（文本不可提取），体系存在已知盲区。
