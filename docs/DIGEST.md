# DIGEST — 朱辰彬古筮六爻体系精华

> 不读全书、只看精华。蒸馏自朱辰彬 8 部著作（约 130 万字语料），2026-08-08。

## 一句话体系

**朱氏六爻 = 摇钱起卦 + 两层面分析（吉凶层面循卦理、应期细节层面取象）+ 七步断卦 + 意念决定论 + 现状对轨验证。**

## 三大基石

### 1. 两层面严格分离（朱氏体系最大特色）

- **吉凶判断层面**：只论卦理（生克冲合、旺衰组合），严谨细致、泾渭分明。回答"成不成、吉不吉"。
- **应期细节层面**：灵活飘逸、择象套用。回答"何时应、有何细节、如何趋避"。
- **致命误区**：把细节层理论（月绊、化绝、化进退）拿到吉凶层用——这是初学者第一大错误。

### 2. 动必有因（动爻是核心）

- 爻不会无缘无故发动，动爻专门围绕世爻/用神转动
- 动爻要辨有用无用：无用四型（回头克/化退/化破散/化绝）共同特征=动而变衰
- 内因重于外因：动变组合（内）为主，日月组合（外）为辅
- 自占自事世爻之动无无用概念，运动方向唯一（只趋向自己的变爻）

### 3. 意念决定论 + 现状对轨

- "只答心念不答口述"：卦象反映心中疑惑，不回答口中之问
- 错卦正显、占此应彼（另兆）、显像就重避轻、意念扶正伐邪
- **对轨**：先把卦象显示的现状信息与客观事实对证，符合才推未来——这是朱氏"科学性"的基石

## 断卦七步（专业）/ 三步（入门）

**七步**：①核实来意（对轨）→ ②明确用神（定位）→ ③吉凶定性 → ④应期推测 → ⑤细节铺开 → ⑥事外解读（占此应彼）→ ⑦趋吉避凶（化解）

**三步**（初学者）：取用神 → 断吉凶 → 推应期

**静卦三步骤**：一看用忌持世（用神持世吉/忌神持世凶，逢破四种例外）→ 二看世用生克（用生世吉、用克世凶，四特例反吉）→ 三参照"用旺世兴"

**动卦五局**：吉=世用受生、用神生世、用旺世兴；凶=用神衰败、世爻受伤、世用受克、用旺世衰、用神克世（求财/行人/医药/忧患四例外）

| 技法 | 要点 |
|---|---|
| 用神选择 | 六亲取用为主；客观取用（对证现状）；真假用神五特征（世应/两动/日月/空墓） |
| 暗动六条件 | 月旺受冲、月气受冲、冲空、动爻趋旺、用趋世兴、动不为散 |

## 股市应用三板斧

**专业技术（铺垫）+ 易理指导（关键）+ 古筮参考（参考工具）**——古筮法不能作为依赖的决策工具（"不谋专事"属性）。金融博弈专题最难：市场里人心态最容易改变，卦随念转；起卦无主观定义时成"自然卦"（六亲归类行情：父母=抛盘、财=获利、兄弟=破损、官鬼=震荡）。

## 最容易被记住的教训

1. **月令之合不是"月绊"**——吉凶层面月合只论合旺
2. **用神克世不一定凶**——求财/行人/医药/忧患四类反吉
3. **自占病取世爻为用**，不是官鬼
4. **静卦用神持世逢破/无根是凶**，不是无条件吉
5. **子孙动化鬼是卦意夭折凶兆**，但可防可解
6. **卦不对题先查"占此应彼"**——卦象舍轻就重、舍小事报大凶
7. **起卦失误（无心）不废卦**——错卦正显
