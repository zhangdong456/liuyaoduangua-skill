# 自动准备微调数据

这里保存自动检测和生成的 fine-tuning 数据，不会自动改写 `references/` 基础规则。

## 自动门槛

每次案例新增或反馈更新后，agent 会自动检查：

- 至少 100 个已完成复盘的案例；
- 至少 30 个高质量且预测正确的案例；
- 所有 partial / wrong 案例都有合法的错误类型标签；
- 至少一个个人规则候选有 3 个以上独立支持案例、无反例，并达到最低置信度。

门槛满足后，自动生成 `output/dataset.jsonl`、`output/status.json` 和 `output/report.md`。数据采用聊天格式，只使用预测时可见的卦面与断语，不把事后结果泄漏进训练输入。

当前功能自动准备数据包，不自动调用外部模型微调接口；是否提交外部训练仍由用户确认，避免把污染案例永久固化。
