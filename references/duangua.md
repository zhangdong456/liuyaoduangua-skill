# 朱氏六爻吉凶判断核心框架

## R — 原文 (Reading)

> 古筮六爻这种"对轨 + 预测"的推算步骤，充分体现了古筮预测法的严谨。……要求预测者，必须先根据勾画出虚拟的事态过去现状信息，与事情已经发生了的客观事实，一一对证切合。若在"对轨"过程中，卦象信息与客观现实完全对接上，那等于是已经正确掌握了事态运动轨迹的一半规律，再以此为基础，推算将来事态的趋势变化，那就更有把握。
>
> — 朱辰彬，《古筮真诠》第八章

## I — 方法论骨架 (Interpretation)

朱氏断卦的核心是把分析分成**两个层次**，严格不混用：

- **吉凶判断层面**：只论卦理（生克冲合、旺衰组合），重逻辑重因果，回答"成不成、吉不吉"。
- **应期细节层面**：允许飘逸思维、取象联想，回答"何时应、有何细节"。

**专业断卦七步流程**：①核实来意（对轨）→ ②明确用神（定位）→ ③吉凶定性（定性）→ ④应期推测（应期）→ ⑤细节铺开（细节）→ ⑥事外解读（兼象，占此应彼/事外信息）→ ⑦趋吉避凶（化解）。其中 1/2/5/6/7 步需"对轨"配合，3/4/5/6/7 步涉及"预测"。初学者先用三步：（1）取用神、（2）断吉凶、（3）推应期。

吉凶判断的主线：

1. **先辨卦种**：事卦 / 心态卦 / 现状卦 / 应期卦 / 指导卦 / 特殊时效卦 / 双核卦 / 连占卦。卦种错则全盘皆错。
2. **取用神**：六亲取用为主（父母=文书长辈，官鬼=事业疾病，妻财=钱财，子孙=医药子女喜神，兄弟=劫财同辈）；特殊用神（世爻为用、星煞为用、六神为用、十二宫为用、应爻为用）；**真假用神五特征**（世应/两动/日月/空墓）鉴别；用神多现时对证现状取用。**特指单位求职例外**：问的是某一家明确公司、已进行的面试或录用结果时，官鬼虽可代表岗位，但若父母爻临应、发动且直接对应公司/面试/offer，应将父母作为本题的核心用神或并列主用神，不能机械以伏藏官鬼压过应爻父母；最终以哪一六亲具备特指位置、动兆和世用生克链为准。
   - **动态取用（元原则，勿死板锁六亲标签）**：用神选取要跟"动爻/动态"走，不能拿六亲标签把判断框死——①先数动爻、再定用神（动必有因，动爻是事态变化的载体）；②先辨事象结构："自己谋自己"对轨世爻/用神，"求对方"（调岗/求职/求领导/求人办事）对轨应爻；③追动爻生克链，尤其"生世/生用"之爻自己是不是正被其他动爻克破（回克/夹克/聚党克）——被克破则生路断，不作吉论；④静态旺衰是底子、动态生克是胜负手，勿用"用神旺相"掩盖动爻破局（详见 yicuodian 条目48）。
3. **看日月动变四因素**定爻之旺衰：
   - 月令旺四（临/合/生/扶）、衰四（冲/克/克月/生月）
   - 日令旺五（临/合/生/扶/长生帝旺）、平二（克日/生日）、衰二（被克/绝）
   - 动变：趋旺（受生/合局生/回头生/化进/变临日月）与趋衰（受克/合局克/回头克/化退/化绝/化破散）
4. **辨有用无用动爻**：无用动爻四型=动而变衰（回头克/化退/化破散/化绝，且无回头作用）；世爻之动无无用概念。**辨动爻前先扫三合局**：本卦动爻＋其变爻凑齐三支即成三合局（不要求全是明动爻），含忌神的三合局（如兄弟局）按聚党合力论，凶度远超单动爻；局中卷入用神/世财=被其消化。例：随之涣，亥水动、戌土动化卯木、亥化未土→外卦合成亥卯未兄弟木局劫财。**判回头克前先查日月组合成色**：动爻构成特殊旺相日月组合（如月建临值＋日辰生扶）时回头克暂时失效，该动爻可参与复合连动——离之颐抽查案（jingyan-ku 案例 20）：官鬼亥水特旺不怕回头克，妻财→官鬼→父母（暗动）连环相生生世，压力转化为利好。**临场自查**：凡断"动而化衰/化克即废"之前，逐动爻过一遍四因素清单，勿因结论已倾向吉/凶就跳过此步（见 yicuodian 条目 44"知识在册、临场漏用"）
5. **世用关系定性**：四大吉局（世用受生/用神生世/用旺世兴）+ 五大凶局（用神衰败/世爻受伤/世用受克/用旺世衰/用神克世）。
6. **静卦三步骤**：一看用忌持世（用神持世即吉、忌神持世即凶，逢破有四种例外）、二看世用生克（用生世吉、用克世凶，求财/行人/医药反吉）、三参照"用旺世兴"。
7. **对轨验证**：用日月动变等显示的信息与客观现状对证，不符则持谨慎保留。

### 专项一：感情/婚姻卦（高频）

- **取用**：女测感情/婚姻取**官鬼**（代表丈夫/男友）；男测取**妻财**；无亲缘时世=自己、应=对方，有亲缘取对应六亲
- **应爻发动**=对方有重要动向，吉凶层为"半个用神"
- **子孙持世（女）**：克官鬼，多为不利婚姻——理性克制、排斥、挑剔独立而难成；男测兄弟持世同理主竞争阻碍
- **兄弟爻**：感情中=竞争者、第三者、朋友意见干扰；**父母爻**=婚姻证书、长辈、稳定关系（临朱雀=口舌争吵）
- **六合卦（主卦）**=交往多时拖延良久；**六冲卦**=突发多变近期生变；**卦变六合**=趋势缠绵难决；**卦变六冲**=短期多变不能恒久（长事不利）
- **六冲变六合=散而复聚、离而必合**（特例，不看用神即吉：婚姻先吴越后朱陈、功名先难后荣、求财先难后易）
- **吉凶核心**：用神旺+世兴=可成；用神衰/世受伤/世化衰=不成或受伤
- 案例佐证：卦评例24（悔婚离之旅六冲变六合→此婚一定还成）、卦评例39（泰卦兄弟持世克财，妻财亥水得月生旺+临马暗动"心去难留"→生离之兆）、案例集例10（复合：官鬼两现相冲临白虎=非和平分手；复合后变爻冲世=须改脾气否则再分）

### 专项二：灾卦四公式（人身安全预警）

卦象"避轻就重"，遇及身及亲之危时优先报警。四公式（满足任一即警惕，时效多≤半年，留现状/细节线索定位所指）：

1. 日月皆克世爻（或相关六亲），且日月入动爻相克
2. 众鬼发动克世（或相关六亲）
3. 世爻发动变出官鬼回头克
4. 日月皆克世爻 + 世化回头克（佐证实例相对最少）

灾卦并不可怕，是善意提醒——清晰定位真实所指与时效范围，可防可解。

### 专项三：忌神无力七条 + 用神无根

- **忌神无力七条**（休囚不动 / 静空破 / 入墓 / 化退 / 衰绝 / 化绝破克散 / 与元神同动）——但**须用神有气**才成立
- **用神无根**（月破日克）=元神有力亦难生（如大过之鼎，卒于冲去元神之日）

### 专项四：银行开卡疑虑的风险线复盘（2025-12-08）
- 具体卡/资料可取父母应爻，但卡是否涉诈、是否追责，吉凶核心仍看官鬼风险线。
- 《水山蹇》、白虎、灾煞只能作背景或细节，不能越过卦理直接定凶；应爻父母静而无发动，也不能仅凭六神星煞断其必有问题。
- 本案玄武官鬼午火月破、日克，动化子孙亥水回头克，并受旺子孙子水发动制约，官鬼无力克世；实际“后续未发现问题”验证了应以无力官鬼定性，而非把父母受压扩大成确定的风控限制。

### 专项五：事业/单位卦的日月特指

- **月令=决策层（老总）**，**日令=直接管理者/同僚**；日月直接相冲=上下两派系、两思路，单位难团结
- 间爻（三爻）发动隔世应=间爻阻隔，找人活动受阻
- 六冲变六合多义：须先问清"主动策划"还是"被迫"——用神定性随真实心态变（主动=自我放弃原单位；被迫=同僚计划取代你）
- **调岗/求领导答应之事（对轨应爻）**：调动、安排岗位、求领导给与等"求对方（领导/单位）"之事，成败枢纽在**应爻（对方/领导）**，不能只以世爻官鬼旺相断"用旺世兴"。应爻发动化回头克＝对方态度反转、结果被克（五爻君位尤其代表"领导不给调"）。凡"生世"之爻（如财生官）自身正被两忌聚党克破者，其生路已断，不作吉论。案例见 jingyan-ku 案例22（临之需调岗，反馈未成）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 坎之谦（房地产老总问项目投资）
- **问题**: 老总摇卦问项目投资求财
- **方法论的使用**: 应爻妻财午火发动冲世，两土官鬼同动，火土连动克伤世爻子水——官鬼克世凶兆；兄弟持世=需前期投入的项目；变卦谦=前景潜伏不兴
- **结论**: 两个项目将是非祸根不断，财难得且不得安宁，不宜贸然上马
- **结果**: 作者据此劝其谨慎调研再定

### 案例 2: 用神克世反吉（求财财爻克世）
- **问题**: 自占求财，财爻发动克世
- **方法论的使用**: 自占求财卦见财爻作为有用动爻克世，只要世爻在日月其一获生扶、总体平相，即为有财之兆（用神克世反吉的四种特例之一）
- **结论**: 得财但过程压力大/辛苦（财克世细节=压力或另损）
- **结果**: 朱氏明确这是吉局特例，与一般用神克世为凶不同

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **确认卦面完整信息**
   - 完成标准: 收集齐日月干支（含旬空）、主卦变卦、六亲世应、动爻及其变爻；缺信息先向用户补齐或说明局限

2. **辨卦种与取用神**
   - 完成标准: 判断事卦/心态卦/现状卦/应期卦/双核卦等；按六亲取用，必要时用真假用神五特征鉴别、对证现状取用
   - 判停条件: 若卦种特征模糊（事卦信息与心态信息都明显）→ 用"心念爻"鉴别（子孙官鬼在心念爻=心态卦）

3. **评估日月动变四因素旺衰**
   - 完成标准: 对用神、世爻分别评估月令/日令/动爻/变爻四因素，得出旺衰定位；识别特殊日月组合（旺相式/衰败式）与太过卦

4. **辨动爻有用无用**
   - 完成标准: 每个动爻按"无用四型"（回头克/化退/化破散/化绝）筛选；三合局形成时单爻趋势定义不适用（世爻除外）；复合连动按"三合局优先、目标围绕世用、世爻不参与连动"分析

5. **世用关系定性吉凶**
   - 完成标准: 对照四大吉局/五大凶局定性；注意四种"用神克世反吉"特例（求财/医药/行人/忧患心态）；对轨验证——卦象显示的现状信息与事实对照

6. **输出断语**
   - 完成标准: 给出吉凶定性 + 关键卦理依据链（为什么吉/凶）+ 若需应期则交 `zhuchenbin-liuyao-yingqi`

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只问应期不问吉凶 → 用 yingqi（应期卦属于应期 skill）
- 问卦象细节取象/人物关系读心 → 用 jixiang
- 非摇钱卦（时间/梅花）→ 体系不适用
- 心态卦（忧患/疑虑之占）→ 喜忧神规则优先，不套用事卦世用关系

### 作者在书中警告的失败模式

- **两层面混用**: 把细节层面的"月绊""化绝"拿到吉凶层面断，是最大误区
- **用神克世一律断凶**: 求财/行人/医药/忧患四类特例会反断为吉
- **动而化破一律凶**: 自占自事世爻动而化破是假破（世爻运动方向唯一，聚焦变出六亲）
- **忽视对轨**: 卦象现状信息不与事实对证，真假用神不分
- **静卦用神持世逢破仍断吉**: 无根/逢破为凶

### 作者的盲点 / 时代局限

- 部分规则（如"用趋世兴""心念爻定位"）依赖经验判断，客观可证伪性弱
- 吉凶判定最终仍需结合事主现状核实，纯卦面推演有误差率，只能作参考工具

### 容易混淆的邻近方法论

- 传统"世应生克"派断法（如只看世应冲合）——朱氏强调动必有因、动爻围绕世用
- 梅花易数体用断法——体系不同勿混用
