# 朱氏卦象细节取象与卦意分析

## R — 原文 (Reading)

> 卦象可透过用神替身法的手段，绕过事卦与心态卦交融混淆的大弯子，清晰地发出吉凶趋势提示。让事卦用神藏伏在心态卦用神之下，以心态卦的喜神与忧神作为事卦用神的替身，按心态卦的模式显示吉凶趋势。……卦意用神法要应用精通，对六爻各类学识的全面兼容要求很高，因为这往往是吉凶与细节、据理与取象、用神与世应之间关系，做到层次分明高度圆融的综合体现。
>
> — 朱辰彬，《古筮真诠》第二十五章

## I — 方法论骨架 (Interpretation)

吉凶定性的主线走卦理（duangua），而**细节层面的灵魂是"飘逸思维"**——以易理为依托的丰富联想。本 skill 涵盖：

1. **卦意分析法（直读法）** 12 法：不通过生克冲合、直接读卦象结构的取象法——世化用忌（自占自事）、用忌互化（代占）、鬼用互化（祸患纠缠）、世动化鬼（是非纠缠）、世用背向（三吉三凶：变爻与世用相合/相冲）、搭桥趋变（两动爻桥接变爻）、牵连聚合（动爻相连寓意聚散）、代入确认/替身法（同类/相冲/相合者代表对手朋友）、藏爻确认（用神藏伏定位）、间爻阻隔（阻隔成则凶）、冲合预兆（与用神冲合者的变化）、动动相连（动爻优先相连）。
2. **取用神进阶**：用神替身法（飞爻/动爻作替身）、拓扑用神法（五行/星煞/六神/十二宫类象取用）、世应之风采（应爻=固定点数据库、无声代言者）。
3. **双核卦**：特指事占（目标寄托在某指定事物/人物）——用神旺只代表事成，须结合应爻/动兆判断"是不是这个特指对象"。三个常见类型：对比信息（相冲/同类/相同）——无关型不干预、对比型干预、关联型干预。
4. **读心术（心念爻）**：心念爻只藏在世爻位与君爻位之间（对位爻/藏爻/君爻四级定位），用于区分事卦/心态卦、洞察事主真实想法；"问病心念见鬼=担心，见子孙=求医"。
5. **现状对轨（对轨）**：日月（外部环境过去现状）、带日月之爻（日月往来=常态）、暗动（正在发生）、冲中逢合（现状）、旬空（尚未发生）、持世之爻（现状或最终结局）——用卦象显示的现状信息与客观事实验证。
6. **特殊卦种**：指导卦（化墓之动/带暗动/带日令月令的动变=指导信号，变卦卦辞=半个指导卦）、现状卦（所有信息=现状反映）、连占卦（针对前一卦疑惑的补充回答，信息粗放、放大一层看）、太过卦（太旺亢龙有悔/太衰，短期停顿/趋势反转，注意隐性太过）、灾卦（日月克世/众鬼克世/世化鬼回头克；时效≤半年；善意提醒可化解）。

### 六神细节取象表（细节层专用，不操控吉凶）

| 六神 | 细节寓意 |
|---|---|
| 青龙 | 色情/婚姻喜庆、出身好/长相好、礼仪、酒色、吉祥 |
| 朱雀 | 口舌/争吵、表达/文书/信息、歌唱（临朱雀父母=证书口舌） |
| 勾陈 | 迟滞/拖延、牵连/纠葛、田土/房产、陈旧 |
| 螣蛇 | 虚惊/怪异、纠缠/缠绕、狐疑、梦魇 |
| 白虎 | 血光/丧事、凶险/创伤、西医/手术、刀伤 |
| 玄武 | 暧昧/隐私、暗昧/不明、偷盗/欺骗、私心/想当然 |

> 铁律：六神星煞只用于细节层定位与现状对证，**不能单独操控吉凶定性**（"卦凶六神有凶说，卦吉六神有吉说"）。

### 心念爻提取四步法（读事主真实想法）

心念爻隐藏于世爻位与君爻（五爻）位之间，只用于细节层读心，不能据其取用神：

| 步骤 | 查看位置 | 条件 |
|---|---|---|
| 1 | 世爻变卦的对位爻 | 世爻未动 + 对位爻与世爻不同 |
| 2 | 世爻所藏的藏爻 | 世爻动了或对位与世同 + 藏爻与世不同 |
| 3 | 君爻（五爻） | 前两步不成立 + 君爻未动且与世不同 |
| 4 | 君爻的藏爻 | 前三步不成立 + 君爻在动 + 君爻藏爻与世不同 |

心念爻分析：问病见鬼=担心；见子孙=求医药；见用神之墓=想知道病危应期；心念爻带子孙/官鬼=心态卦心念，带其他=事态心念（用于区分事卦/心态卦）。

### 神煞取象（细节层）

- **马星**：带马星=动的/远的；冲马星=不动的/近处；合马星=动的寓意。问距离：带马星很远、合马星较远、冲马星为近
- **禄神**：带禄=值钱的事物（妻财临禄库=家中有钱）
- **桃花**：问感情合桃花=较漂亮；问聘用合桃花=较有名气/身份突出
- 案例（男测姻缘断相貌）：应爻变爻与马星相冲=本地人；应爻临财（辰为禄神之库）=家境优秀；官鬼临青龙=身材高大；官鬼与桃花作合=相貌不错；应爻临朱雀=能言善道

### 世应同类爻＝两对象对比取象（★实战补强，2026-08 火箭班卦）
当**世应持同类六亲且相冲**（如世父母戌土、应父母辰土，辰戌冲），两爻常代表"两个并列选项"的对比，而非"我与他"：
- 应爻在前（临青龙）＋带谋星等指向性星煞＝**想谋的那个选项**；世爻在后（临腾蛇）＝将就/落定的那个。
- **分动兆联动追踪法**：把每个候选选项的生克链分别追到同一落点（如孩子＝子孙），比较两条链对落点的作用——戌土线"生兄弟→兄弟生子孙"，子孙暗动＝此班滋养孩子；辰土线隔位不能生申只能直接墓克子孙，子孙又日破＝彼班墓压孩子。两链一划吉凶自明。
- 伏吟临世＝纠结难受但恰是合适归宿；该线若连环生助落点，可断"在此处发展不错"。
- 教训：勿只锁单一用神评旺衰，先用直读铺开世应对比结构再做分链联动；排盘神煞在特指定位上很有用。

### 搭桥趋变的精确边界（纠偏）

- **正确定义**：搭桥是两爻互变的**桥梁**，不是源头。搭桥后形成的变爻**不能回头生克搭桥的源头**——若变爻能回头作用动爻（如"世官→卯木→未土回头克亥水"，未土能回头克世），则根本不是搭桥趋变
- 适用前提：吉凶层面两动爻之间不能存在针对世用的卦理生克；两动各自变爻不能回头生克世用；两动变爻不能合成三合局；搭桥吉凶定性在变出六亲而非回头作用

### 多元元素事占（"某人有利我否"）

- 先定世爻（以自己损益为中心），但**不能只看世爻旺衰**——问题常有两个核心元素（自己+某人）
- 例：应爻辰土（某人）不动，卦中丑土发动生世 → 真正起作用的是**另一个人（丑土）**，非此人（辰土）；若单纯世爻为用断"世得动生旺相=有利"会误判
- "做什么生意有财"同理：想做的生意子孙没动，却是另一个子孙动 → 此生意无财，有财的是另一生意

## A1 — 书中的应用 (Past Application)

### 案例 1: 妻财爻藏于子孙爻内的替身法（问妻病）
- **问题**: 问妻子病，事卦用神妻财爻藏伏
- **方法论的使用**: 妻财爻藏于子孙爻之内 → 让喜神子孙作为妻财的用神替身，按心态卦模式昭示趋势
- **结论**: 以喜神子孙的状态判断妻子病势吉凶
- **结果**: 绕过事卦与心态卦混淆，直接读出吉凶趋势

### 案例 2: 指代错位（双核卦警示）
- **问题**: 问"与指定某人合作是否有财运"
- **方法论的使用**: 官生世预示能合作，但需确认"是不是这个指定的人"——用神旺只代表事成，须结合应爻/特指对比信息判断对象是否吻合
- **结论**: 卦象可能显示的是另一人/另一单位更有利
- **结果**: 朱氏警示只注重世用易产生分析定性的误导

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **确认吉凶已定，进入细节层**
   - 完成标准: 明确吉凶方向已由 duangua 定性；本 skill 只做细节/取象/现状补充（吉凶层与细节层不混用）

2. **判断卦种与重点信息**
   - 完成标准: 判断是否特指/嫁接事占（→双核分析）、是否指导卦/现状卦/连占卦；锁定动爻、应爻、心念爻、藏伏信息

3. **取象分析**
   - 完成标准: 按需选用 12 种卦意分析法（如世化用忌/搭桥趋变/牵连聚合/藏爻确认等）；用神藏伏时考虑替身法与冲飞露伏；读心念爻洞察事主真实心态
   - 判停条件: 若取象结果与卦理吉凶矛盾 → 卦理优先（"一旦卦象在动变过程中显示出明显的卦理吉凶趋势指引，则必须舍卦意而循卦理"）

4. **现状对轨**
   - 完成标准: 用日月/动变/旬空/暗动显示的现状信息与客观事实对证，验证用神真假、修正解读

5. **输出细节解读**
   - 完成标准: 结合吉凶给出完整解读（成/败 + 过程/人物/心态/现状细节 + 可能的指导信号）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 吉凶未定先做细节 → 层次混乱，先定吉凶
- 卦理已明确显示吉凶趋势 → 舍卦意循卦理，不要强行取象
- 非摇钱卦 → 体系不适用

### 作者在书中警告的失败模式

- **细节层与吉凶层混用**: 搭桥法吉凶定性在于变出的六亲而非回头作用；世用背向法只在无明显卦理吉凶时使用
- **心念爻定位用神是本末倒置**: 心念爻只是想法，与问题不同步，不能据此定用神
- **应爻不可忽视**: 应爻是固定点数据库，完全忽视会严重误判
- **特指误判**: 问指定对象时只用神旺衰会误导（可能显示的是别人/别处）

### 作者的盲点 / 时代局限

- "飘逸思维"开放度过高，同一卦不同人取象可能差异大，难以标准化
- 心念爻四级定位（对位/藏爻/君爻）依赖实践经验，初学者易误用

### 容易混淆的邻近方法论

- 卦意分析 vs 卦理分析：吉凶层面以卦理为纲、卦意为辅；不可本末倒置
