# 朱氏摇钱起卦与装卦

## R — 原文 (Reading)

> 古筮摇钱法并不适用于通过时间、报数、物象等非摇钱方式得出的卦象，因为彼此的成卦方式不同，在分析方法理论上彼此差别也非常大。摇钱而出的卦象有分静卦与动卦，分析重心在于卦中五行六亲的生克布局；能如实传导问卦人真实问卜心态；能客观代入事态现实与过去景象；这些都是摇钱卦独有的优势特征。
>
> — 朱辰彬，《古筮真诠》第二章

## I — 方法论骨架 (Interpretation)

朱氏体系的起卦以"意念如实传导"为核心假设：手摇钱币产生的卦象能反映问卦人的真实心态，这是整个分析体系的前提。因此起卦环节的全部要求都围绕"意念纯净、信息清晰"展开：

1. **工具**：三枚大小厚薄一致的钱币（古铜钱如乾隆通宝，或现代硬币），扁圆薄形状为佳。
2. **条件**：心诚则灵——对占卜持怀疑抵触态度者不宜问卦；有个人信仰者可在摇卦前默念禀告，助聚意念。
3. **流程**：聚念默想所求之事 → 摇钱抛出 → 记录背向 → 重复六次 → 由下向上排卦。
4. **一事一卦**：每次只问一件事；"多问简显、简问多现"——问事越单纯，卦象信息越清晰丰富。
5. **阴阳定义**：以"简虚为阳面，繁实为阴面"区分。三阳=老阳（动变少阴），三阴=老阴（动变少阳），一阳二阴=少阳，一阴二阳=少阴。
6. **排卦**：由下向上排；老阳老阴为动爻，需排出变爻形成变卦。

## A1 — 书中的应用 (Past Application)

### 案例 1: 房地产老总当场求测（坎之谦）
- **问题**: 老总当众摇卦后一言不发，考验能否测出来意
- **方法论的使用**: 按"核实来意"定位——应爻妻财午火发动冲世，变出父母刃星，断其问"项目投资性质的求财"；再按财生两官、两土官发动、主卦六冲，断其"在两处项目中决策投资"且"刚发生不久、有人上门说客"
- **结论**: 求财之占，卦象不利（火土连动克世，官鬼克世为凶兆）
- **结果**: 老总全部对证无误，惊叹"近乎神迹"；但作者强调这并非神迹，而是"核实来意"技术的运用（推测来意把握只有十之五六，核实来意才是技术可控的）

### 案例 2: 错卦正显（书中普遍现象）
- **问题**: 初学者排卦失误、记错阴阳
- **方法论的使用**: 卦象"什么都知道"，能事先洞察无心之失，故"错卦正显"
- **结论**: 无心之失不影响卦象真实显像，不必因起卦失误而废卦
- **结果**: 朱氏明确此说（第一章总论），但强调"一时无心之失"——故意乱卦不在此列

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **确认起卦条件**
   - 完成标准: 确认用户用意念摇钱方式起卦（三枚钱币抛六次），而非时间/报数起卦；确认问事者心态虔诚专注
   - 判停条件: 若用户是时间/报数/梅花起卦 → 说明朱氏理论不适用，建议改用对应体系或改用摇钱法

2. **引导摇卦与记录**
   - 完成标准: 六次抛钱结果完整记录（每次：几字几背），提醒一事一卦、由下向上
   - 判停条件: 用户同时问多件事 → 提示"多问简显"，建议分开各占一卦

3. **排卦与装卦**
   - 完成标准: 排出主卦（六爻阴阳）、标出动爻（老阳O/老阴X）、排出变卦；装好纳甲干支、世应、六亲、六神
   - 注意: 阴阳定义按"简虚为阳"原则（背为阳、字为阴）；由初爻向上排
   - **装卦口诀速查**：
     - 纳甲（浑天甲子）：乾金甲子外壬午、坎水戊寅外戊申、艮土丙辰外丙戌、震木庚子外庚午；巽木辛丑外辛未、离火己卯外己酉、坤土乙未外癸丑、兑金丁巳外丁亥（内卦三爻/外卦三爻）
     - 六亲生克：生我者父母、我生者子孙、克我者官鬼、我克者妻财、同类者兄弟（以卦宫五行属性为"我"）
     - 世应口诀：天同二世天变五、地同四世地变初、本宫六世三世异、人同游魂人变归（按上下卦乾兑离震巽坎艮坤的卦数关系定世爻，应爻隔两位）
     - 六神起例："甲乙起青龙、丙丁起朱雀、戊起勾陈、己起螣蛇、庚辛起白虎、壬癸起玄武"（按日干从初爻向上排）

4. **断卦前定位**
   - 完成标准: 明确问卦性质（事卦/心态卦/应期卦/现状卦等）、初步定位用神候选，再交 `zhuchenbin-liuyao-duangua` 继续

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户明确用时间起卦、报数起卦、或梅花易数等非摇钱方式 → 朱氏六爻理论不兼容
- 问卦者心怀疑虑、嬉戏态度 → 卦象信息混乱，建议先端正心态
- 需立刻得到答案且无钱币在手 → 可用任意三枚硬币代替（大小厚薄一致即可），但不可改用报数法

### 作者在书中警告的失败模式

- **阴阳记反**: 初学者易凭直觉把"○●●"记成少阴，实际"○●●"是少阳（阳面少、阳爻显，由少至多变动的方向决定）
- **由上向下排卦**: 必须由第一次摇出的爻（初爻）在最下，依次向上
- **一卦多问**: 心思复杂或一卦同时问几件事，卦象信息会"多问简显"、杂乱无章

### 作者的盲点 / 时代局限

- "心诚则灵"与"信仰加持"（默念菩萨禀告）等观点缺乏可证伪性，属于经验性主张
- 强调摇钱卦独优，对时间卦/梅花卦的否定带有体系本位色彩

### 容易混淆的邻近方法论

- 梅花易数起卦（时间/数字/物象）——理论体系不同，勿混用
- 蓍草占法——古代起卦法，现代已普遍用摇钱法替代
