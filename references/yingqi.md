# 朱氏应期推断

## R — 原文 (Reading)

> 爻静者，逢值逢冲之期应事，多用于静卦。主事爻静旺者，多会应在逢冲之期；主事爻为衰弱者，较多会应在逢值之期。爻动者，逢合逢值之期应事。如动爻临酉金发动，后遇辰期或酉期应事。月破者，逢填实、补破或出月破之期应事。旬空者，逢填实、逢冲实、或出空期之时应事。
>
> — 朱辰彬，《古筮真诠》第四十章（应期公式归纳）

## I — 方法论骨架 (Interpretation)

应期推断是在吉凶定性之后的第二问："何时应验？"朱氏将应期系统化为可查的公式 + 筛选原则：

1. **公式驱动**：20 条常用公式覆盖各种卦象状态（静/动/破/空/合/冲/三合/三墓/三刑/反吟/伏吟/化进退/藏伏等），每卦按主事爻状态套公式得出候选应期。
2. **筛选原则**：候选应期常不止一个，按 5 条原则收敛——吉断吉应凶断凶应（应期方向与吉凶一致）、盯面不盯点（锁定时间段而非某一点）、应众不应寡（重叠信息优先）、应早不应迟（最早的理论应期最可能成真）、应邻不应单（相邻时令优先）。
3. **变速器识别**：暗动（含带日令而动）、卦变六冲 = 应期**加速**；三合局、三绊、卦变六合、变出渐卦恒卦 = 应期**迟缓**。
4. **时效法则**：短事"日转月不转"（日令主宰、过日失效）；常事"月转日不转"（月令主宰）；长事"日月皆不转、只有太岁动"。
5. **主应期与细节应期**：先定主应期基数（年/月/日），细节应期按主应期元素逢值、相冲再推（如行人戌亥日归，可细推戌亥日的辰巳时/戌亥时）。
6. **特殊应期单位**：股市/短线以"日/旬"为主（极少月年）；房产/长期投资以"月"为短周期（不同于炒股，流程长常一年以上）；占此应彼信息**应近不应远**（应期定月或日，不会是某年）；暗动在股市多应近一两日方向变化。
7. **股市爻位应期法（当日走势）**：用爻位对应时段推当日行情——初爻=开盘段、上爻=收盘段等（详见 gu-shi 类案例），配合动爻逢值逢合/旬空出空定当日高低点窗口。

## A1 — 书中的应用 (Past Application)

### 案例 1: 应期公式的经典验证（月破填实）
- **问题**: 卦中主事爻月破，何时应事
- **方法论的使用**: 按公式"月破者逢填实、补破或出月破之期应事"——实破=临值，补破=逢合，出破=过时
- **结论**: 动变之爻月破多应实破或补破；静爻月破不排除应出破
- **结果**: 朱氏强调"也有可能是众多的应期信息都一一轮过了才会应事"

### 案例 2: 暗动加速（长占快应）
- **问题**: 长事之问卦中暗动
- **方法论的使用**: 暗动是应期加速器——"占长事而用神暗动，乃是慢占快应之兆"
- **结论**: 暗动把应期提速，急者应于时辰，缓者也比预期快
- **结果**: 例证：戌月戊辰日占终身功名得山风蛊，官鬼持世元神妻财暗动，短短五年实现仕途梦想（目的长占快应）

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **确认吉凶定性已定**
   - 完成标准: 明确此卦吉/凶方向（应期须配合吉凶方向：吉断吉应、凶断凶应）；若未定吉凶先转 duangua
   - 判停条件: 应期卦（吉凶无虞只有应期之虑）→ 直接进入步骤 2，但先检查是否"假应期卦"（玄武持世/心念爻异象）

2. **识别主事爻状态并套公式**
   - 完成标准: 按 20 条公式逐条匹配（静/动/破/空/合/冲/三合/三墓/三刑/反吟/伏吟/化进退/藏伏/用多现等），列出全部候选应期

3. **识别变速器调整**
   - 完成标准: 检查是否有加速器（暗动/带日令/卦变六冲）或迟缓器（三合/三绊/卦变六合/渐恒卦），相应提前/推后；检查时效法则（短事日转月不转等）限定范围

4. **按五原则筛选收敛**
   - 完成标准: 用盯面不盯点/应众不应寡/应早不应迟/应邻不应单收敛到时间段；最后分主应期与细节应期
   - 判停条件: 静卦世用无生扶（缺根）→ 提示"应期意外"（好事期盼：应期难定；坏事：长寿之兆）

5. **输出应期结论**
   - 完成标准: 给出最可能应期 + 备选应期 + 依据（公式名+卦面证据）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 吉凶未定 → 先断吉凶（duangua）
- 应期意外卦（缺根）→ 不可强行给应期
- 非摇钱卦 → 体系不适用

### 作者在书中警告的失败模式

- **理论应期过多时**死盯某一点 → 应用"盯面不盯点"锁定范围
- **忽视应期意外** → 静卦世用无生扶是意外信号
- **月合应期的局限性**: 当令之爻与月合之爻是敌人时（如辰月酉金动变午火回头克），月合保三月法则失效，午月即遭殃
- **应期范围太短或太长的事占**不太适用月合应期
- ★**应期单位错配（实战复盘教训，噬嗑卦退费案）**: 纠纷追款/维权类事项因对方蓄意拖延属"常事～长事"，主应期必须以**月**（甚至年）为单位；若误套短事的"日"级公式（如静旺爻逢冲取丑日）会严重失准。识别迟缓信号加权：六爻安静＋勾陈临世＋应爻（对手方）克世用＋用神旬空＝拖延漫长的组合拳，此时静旺之爻的月级"逢值/逢冲"才是主应期（该卦世爻妻财未土静旺，2025 未月起卦，实际 2026 未月逢值退款到位）；日级候选只配作细节应期

### 作者的盲点 / 时代局限

- 应期公式是概率性总结，非绝对规律（"固定套路也有它概率上的准确性"）
- 主应期基数选择依赖断卦者经验，公式无法完全机械化

### 容易混淆的邻近方法论

- 应期加速 vs 吉凶定性：暗动在短事中可参与吉凶定性，在长事中只是应期加速信号——勿混用
